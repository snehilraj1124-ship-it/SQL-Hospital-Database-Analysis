# SQL Hospital Database Analysis

## Overview

This project demonstrates the application of SQL for healthcare data analysis using a hospital database dataset.

The project focuses on querying patient records, performing data filtering, identifying missing values, analyzing demographic information, and generating meaningful insights from healthcare-related data.

---

## Project Objectives

- Analyze patient information using SQL queries.
- Perform demographic and healthcare data analysis.
- Identify missing and inconsistent records.
- Practice SQL data filtering and aggregation techniques.
- Build a structured SQL portfolio project.
